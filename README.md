## ✨ Features

- 📱 **Native Android Integration**: Packaged via `@capacitor/android` for seamless mobile installation.
- 💬 **Multi-Channel Chat Bridges**: Connects directly to **WhatsApp, Discord, Telegram, and Slack**.
- 🧠 **Dual Engine Support**: Seamlessly toggle between local **Ollama** LLMs or ultra-fast **Groq** cloud inference.
- 🎤 **Mobile Voice Interface**: Full two-way voice conversation supported on iPhone and Android mobile browsers.
- 🛠️ **CLI Wizard**: Built-in `setup.js` wizard walks you through configuring bots and testing connections.

---

## 🛠️ Tech Stack

- **Mobile Framework**: Capacitor 8 (`@capacitor/core`, `@capacitor/cli`, `@capacitor/android`)
- **Backend Runtime**: Node.js ES Modules
- **Bridges**: `discord.js`, `whatsapp-web.js`, `telegraf`, `@slack/bolt`
- **Inference**: Ollama, Groq SDK
- **Containerization**: Docker, Dockerfile

## 🗂️ Project Structure

```bash
Alya-OS/
├── android/            # Native Android Studio project generated by Capacitor
├── capacitor.config.json # Capacitor app configuration
├── Dockerfile          # Containerized deployment script
├── package.json        # Dependencies and build scripts
├── setup.js            # Guided setup wizard
├── test_alya.js        # Automated integration testing
├── src/
│   ├── index.js        # Server orchestrator
│   ├── core/           # Config, LLM adapter, persistent memory & personality
│   └── bridges/        # Discord, Slack, Telegram, WhatsApp, Web bridges
└── web/                # Web dashboard and mobile frontend UI
```

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/dakshgoyal1812/Alya-OS.git
cd Alya-OS
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run Setup & Start
```bash
npm run setup
npm start
```

### 4. Build Android App (Optional)
```bash
npx cap sync
npx cap open android
```
