Privacy Policy

Effective Date: July 3, 2026

Welcome to Alisa AI Assistant ("we", "our", or "us"). We are committed to protecting the privacy of our users. This Privacy Policy explains how we collect, use, and safeguard your information when you interact with Alisa through our web dashboard and WhatsApp Cloud API integration.

1. Information We Collect

To provide conversational AI features, we process the following information:

  • Message Content: The text and media messages you explicitly send to Alisa.
  • User Identifiers: Your phone number (when using WhatsApp) or session tokens (when using the Web Dashboard) to maintain conversational context and history.
  • Voice Notes: Temporary audio files sent by you, which are transcribed using the OpenAI Whisper API to let Alisa understand and respond to spoken queries.

2. How We Use Your Information

We use your information solely for the following purposes:

  • To process your queries and generate natural language responses.
  • To maintain conversational memory across message sessions.
  • To generate synthesized voice note responses if voice/audio output is requested.

3. Data Sharing & Security

  • No Selling of Data: We do not sell, trade, rent, or lease your conversation details, phone numbers, or metadata to third parties.
  • API Providers: Your message requests are processed through secure API endpoints hosted by our LLM providers (Groq Cloud, Google Gemini, OpenRouter, and NVIDIA NIM) under their respective API privacy terms.
  • Security Measures: We employ industry-standard secure socket layers (HTTPS/WSS) and encryption to secure your callback webhooks and communication tunnels.

4. User Rights and Data Erasure

You retain full ownership of your conversation history. You can request deletion of your chat history at any time by:

  • Clicking the "Clear Chat" button inside your local Web Dashboard.
  • Sending a message request to clear memory directly.

5. Updates to This Policy

We may update this Privacy Policy from time to time. We encourage users to check this page periodically for any changes.
